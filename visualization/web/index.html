3 · Algoritmos

¿Cómo funciona?

  1. LLM → JSON. El agente convierte el requerimiento en un grafo de recursos validado (nodos + dependencias + conflictos).
  2. Coloración. DSatur / Welsh-Powell colorean el grafo de conflictos: cada color es un lote que corre en paralelo sin colisiones; χ(G) es el mínimo de lotes.
  3. Planaridad. Test de Boyer-Myrvold / LR. Si no es plano se extrae el certificado de Kuratowski (K₅ / K₃,₃) y se planariza con nodos virtuales.
  4. Reporte. El LLM interpreta las métricas (no las calcula) y recomienda la infraestructura mínima.

Todo el cálculo corre en su navegador con el mismo código Python del repositorio (Pyodide / WebAssembly).
